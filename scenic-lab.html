Route Map — real terrain / OSM / IFR charts (requires internet access to load tiles)

Layer switcher is the icon in the top-right of the map. Street layer is CARTO Voyager; terrain layer is Esri World Topo Map — both chosen specifically because they load fine from a locally-opened file (OpenStreetMap's own tile server blocks that; you'd see a "403 Access blocked / Referer required" tile grid if that happens again). The FAA VFR Sectional, VFR Terminal Area Chart, IFR Low, and IFR High layers are all pulled from the official FAA ArcGIS tile service and are United States coverage only — routes outside the US (Victoria Falls, Lauterbrunnen, Milford Sound, Great Glen, Chamonix) will show blank/no tiles on those four layers, which is expected, not a bug.
