LICENSING — IMPORTANT, DO NOT FORGET
CARTO Voyager tiles require an Enterprise license for any commercial/distributed use —
free tier does NOT cover shipping in redistributed software. Esri World Topo Map is
deprecated (unmaintained, could disappear). OpenStreetMap's own server explicitly
disallows this kind of embedded use (that's why it 403'd). NONE of these three are
confirmed safe to ship inside the real Vector app for other users — they're fine ONLY
as Toby's personal lab tool right now (single user, low volume, no automated bulk
requests). Discussed with Toby (~50 users, free app) — low practical enforcement risk
at that scale, but the terms don't scale with user count, so this is a known accepted
risk for the lab, NOT a decision that it's fine to ship. If the shipped-app map feature
ever gets built for real, the safe options are: (a) static screenshot baked in as an
asset (Toby already doing this for personal reference — separate question is whether a
screenshot becomes a *permanent shipped* UI asset, not resolved), (b) self-host a tile
cache, or (c) a paid provider under Toby's own account (MapTiler etc.).
