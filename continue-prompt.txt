## Testing method reminder

Local static server on :8791 (check `netstat -ano | grep 8791` before starting a new one) +
Playwright MCP, driving the real app via browser_evaluate (not just reading code). Aircraft
select is a text input (#aircraftInput) not a native <select> — set .value directly and
dispatch input/change/blur events, then click #generateFlightBtn; the field's own autocomplete
normalizes the value, so calling internal functions directly (e.g. probeDispatchFlight) needs
the real activeFleetSpecs KEY (e.g. "PA24"), not the display name — look it up via
Object.keys(activeFleetSpecs).find(...) first. Stylesheet changes need a cache-busted reload
(plain reload can serve stale cached styles.css) — append a query string like ?cachebust=N.
Close the Playwright browser and run /compact after finishing tests, per CLAUDE.md.
